# Legend-Level PowerPoint Instructions for Cline

When working with presentations or PPTX generation:
1. Always prioritize native editable PowerPoint objects (tables, shapes, charts, text) over flat bitmap exports.
2. In-place template preservation: When given a reference `.pptx` or `.potx`, surgically edit only the targeted slide objects. Do not regenerate the entire deck.
3. Write action titles for slides that summarize the conclusion rather than generic topic labels.
4. Separate vector data lanes (charts, numbers, diagrams) from raster image lanes (photos, heroes).
5. Always verify slide layouts for text overflow and shape collisions.
