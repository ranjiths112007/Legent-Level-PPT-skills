# Presentation Accessibility

- Give slides meaningful titles.
- Add useful alt text to meaningful visuals.
- Mark decorative images as decorative where supported.
- Ensure logical reading order.
- Use sufficient contrast.
- Do not communicate meaning by color alone.
- Use meaningful hyperlink text.
- Use table headers and simple structures.
- Avoid excessive text embedded in images.
- Provide captions/transcripts for media.
- Test keyboard and screen-reader workflows where possible.

Visual order and object insertion order can differ. Do not infer accessibility solely from a screenshot.

Automated candidates: missing titles/alt text, known-color contrast pairs, empty hyperlinks, table metadata, suspicious reading order. Human review remains necessary for whether alt text conveys meaning, whether a chart is understandable, and whether the narrative is accessible.
