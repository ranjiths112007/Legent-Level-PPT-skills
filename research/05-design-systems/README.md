# Design Systems for Presentations

A design system lets slides feel related without becoming repetitive.

Define canvas, safe margins, grid, spacing, semantic colors, type roles, line/shape styles, chart palette, image treatment, footers and recurring components.

Maintain patterns for title, section divider, single insight, comparison, process, timeline, metric, chart, table, quote, case study, image-led and closing slides. Choose by message, never mechanically rotate layouts.
