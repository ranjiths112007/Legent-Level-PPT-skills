# Layout and Composition

**Status:** Reference · **Last reviewed:** 2026-11-21

Patterns include title/thesis, section divider, single insight, comparison, timeline, process/flow, funnel, hierarchy/org chart, KPI, chart with takeaway, table, quote, case study, image-led narrative, map and appendix.

Choose by semantic intent: sequential, comparative, hierarchical, geographic, quantitative or illustrative. Ask what the audience should notice first, how many content units matter, what must remain editable, and whether a visual is needed.

Defects: uneven margins, misaligned edges, inconsistent gaps, accidental overlap, content near edges, stretched images, dense blocks, repetitive card grids, competing focal points.

Algorithm research: pattern selection, constraint-based geometry, grid snapping, rectangle packing/collision detection, text measurement and iterative fitting, rule-based placement, LLM-proposed layout with deterministic validation. Do not rely on LLM intuition for exact geometry.
