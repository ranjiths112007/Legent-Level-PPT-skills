## Research notes
- The many-ppt-skills catalogue reported 227 tracked skills and said 39 were manually reviewed, with its data refreshed 2026-09-04. This is a discovery index, not proof that every listed project is active, free, or high quality.
- SlideSpeak requires SLIDESPEAK_API_KEY, so its public skill source does not make the execution free.
- Some projects have unclear or unverified license status in this review. Verify each repository LICENSE, bundled assets, fonts and dependency terms before copying code or redistributing.
- The 10 main reviews are selected for distinct approaches: native PPTX, HTML-first, story-first, deterministic rendering, modular skill composition and raster image generation.
