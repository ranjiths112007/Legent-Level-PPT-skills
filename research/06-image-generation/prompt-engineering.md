# Prompt Engineering for Presentation Images

**Status:** Practical reference  
**Last reviewed:** 2026-11-21

## Prompt template

```text
Purpose: [what this visual communicates]
Subject: [specific subject]
Context: [environment and details]
Composition: [placement, negative space, focal point]
Viewpoint: [camera angle / perspective]
Style: [photographic / editorial / isometric / vector / 3D]
Lighting: [direction and quality]
Palette: [design-system colors]
Aspect ratio: [target image region]
Slide placement: [left/right/full bleed/background]
Text constraints: no embedded text, labels, logos or watermarks unless required
Avoid: [unwanted objects, clutter, distortion]
```

Reserve negative space where text will sit. Keep focal subjects away from crop boundaries. Match visual direction to slide flow. Ask for the intended viewpoint and distance.

Avoid vague prompts, asking image models for accurate charts, long text embedded in images, incompatible styles, unauthorized logos, or failing to describe slide text space.

Record prompt, model/version, settings, output, reviewer score, artifacts and use decision for every experiment.
