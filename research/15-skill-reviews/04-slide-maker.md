# Skill Review 04 — slide-maker (Addsum)

- Repository: https://github.com/addsumtech/slides_maker
- README: https://github.com/addsumtech/slides_maker/blob/main/README.md
- License: MIT.
- Reviewed: 2026-11-21. Evidence: primary README; SKILL.md path not confirmed in this review.

## Purpose
Open-source AI skill producing native editable PPTX from papers, repositories, documents or topics, with a generation script saved for later revision.

## Contents
Installable skill; around 30 advertised visual templates; two palettes and seven page types per template; photo/illustration templates and native-shape templates; outline/design confirmation; rendered-slide review; optional independent critic; native chart/equation, speaker-note and click-build animation features advertised.

## Agent workflow
1. Accept source paper, code repo, document or topic.
2. Clarify audience, duration, slide count and language/style.
3. Choose a template or reference deck.
4. Confirm outline and design.
5. Generate editable PPTX plus generation script.
6. Render slides and select level of independent review.
7. Iterate and deliver.

## Strengths
Large template variety; editable PPTX central; saved build script aids reproducibility; human confirmation before build; charts/equations/notes; independent critic stage.

## Weaknesses and risks
README claims require independent tests for editability, animation and compatibility. Large template sets can privilege style selection over narrative. Some styles rely on images. Critic independence and review quality need measurement. Runtime dependencies must be checked against current release.

## Best fit
Academic/research and technical decks, teams valuing editable PPTX and template variety.

## Ideas to adopt
Save generation script; previewable template library; confirm outline/design; support native equations/charts/notes; selectable review stage.

Free/open-source skill code does not guarantee free model, image API or infrastructure usage.
