# Contributing

Thank you for helping improve this research base.

## Valuable contributions

- A reproducible PowerPoint failure with input file, expected result, actual result, and software versions.
- A Reddit/forum complaint with the direct URL, date, context, and a concise summary.
- A primary technical reference.
- A competitor feature verified from its repository or official docs.
- A benchmark with test deck, environment, scoring rubric, and results.
- A proposed design, accessibility, typography, rendering, or PPTX engineering improvement.

## Evidence format

For each claim, record:
- Claim:
- Evidence type: primary source / user report / measured result / hypothesis
- Source URL:
- Publication or access date:
- Product and version:
- Reproduction steps (if applicable):
- Limitations:
- Confidence: high / medium / low

## Research quality rules

1. Do not invent user quotes, vote counts, product capabilities, or test results.
2. A Reddit post is evidence that a person reported an experience, not proof of prevalence.
3. Prefer official, versioned documentation for API and file-format facts.
4. Record source access date; documentation can change.
5. Distinguish visual similarity from PPTX editability.
6. Never publish private presentations, credentials, personal data, or copyrighted assets without permission.
7. Do not embed API keys or real customer data in examples.
8. Keep generated test files clearly labeled synthetic.

## File conventions

- One subject per Markdown file.
- Use descriptive filenames and relative links.
- Keep the source register updated.
- Add Mermaid diagrams when useful.
- Add status and last-reviewed date to technical pages.
