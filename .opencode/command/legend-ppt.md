# /legend-ppt

Generate a complete, professional, editable PowerPoint presentation from a prompt, outline, or document.

Follow the instructions in `skills/legend-ppt/SKILL.md`:
1. Extract audience, outcome, and scope.
2. Formulate action titles for every slide.
3. Select layout and design tokens.
4. Construct native OOXML PowerPoint elements.
5. Inspect and verify against visual defect rules.
